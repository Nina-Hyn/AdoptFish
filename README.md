# Adopt a Fish

Emotionally Responsive Floating Companion Robot Based on Spatial Perception

**Quiet Company** · Team T20251891 · UCMP 6050

Peb (from “pebble”) is a fish-shaped floating companion that uses three-dimensional movement to offer responsive companionship while respecting personal boundaries.
